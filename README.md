**העלה את הקבצים ישירות לשורש — לא בתוך תיקייה!**

### שלב 1 — Repository
1. github.com ← "New repository"
2. שם: `financeflow` (קטן בלבד)
3. **Public** ✓
4. "Create repository"

### שלב 2 — העלאת קבצים
1. לחץ "uploading an existing file"
2. חלץ את הזיפ ← גרור **את כל הקבצים** (לא את התיקייה!)
3. "Commit changes"

### שלב 3 — GitHub Pages
1. Settings → Pages
2. Source: **main** → **/ (root)**
3. Save → המתן 2 דקות
